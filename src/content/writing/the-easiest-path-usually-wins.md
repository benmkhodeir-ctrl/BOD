A process can be technically available without being behaviourally available.

If the intended path needs more knowledge, more steps or more effort than the obvious workaround, the workaround has a structural advantage.

That does not prove what any individual person will do. It does give me a useful question whenever I see the same failure repeat:

**What is the easiest available path at this exact moment?**

Sometimes the lever is not more instruction. It is making the right action easier.
